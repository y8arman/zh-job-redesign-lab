Workshop beitreten

Live

So funktioniert's

Beitreten: QR-Code auf der Leinwand scannen oder den Link öffnen, Code eingeben, Alias wählen. Ein Einstieg ist jederzeit möglich, auch mitten im Workshop.

Mitmachen: Sobald der Host ein Modul startet, erscheint die Eingabe auf Ihrem Gerät. Antworten mit einem Tipp, bei Texten und Reglern das Senden nicht vergessen.

Challenge-Punkte: Nach dem 3-2-1-Countdown zählt Tempo. Richtig bringt 500 bis 1000 Punkte, je schneller, desto mehr. Jede weitere richtige Antwort in Serie gibt +100 Bonus, bis maximal +500. Falsch oder keine Antwort: 0 Punkte, die Serie endet.

Module: Je nach Playlist: Stimmungsbild, Wortwolke, gemeinsamer Aufgaben-Kompass, Wissens-Challenge und Betroffenheits-Voting.

Ergebnisse: entstehen live auf der Leinwand und lassen sich dort als Bild sichern.
